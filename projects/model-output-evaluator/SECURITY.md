# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly by emailing the repository maintainers. Do not open a public issue
for security vulnerabilities.

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact.

We will acknowledge receipt of your report within 48 hours and aim to provide
a fix or mitigation within 7 days for critical issues.
