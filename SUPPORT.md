# Support

## How to Get Help

### Documentation

Each project has comprehensive documentation in its `docs/` directory and `README.md`.

### GitHub Discussions

For questions, ideas, and general discussion, please use [GitHub Discussions](../../discussions).

### Bug Reports

For bugs, please open a [GitHub Issue](../../issues) with:
- The project name
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Python/Node version)

### Security Issues

For security vulnerabilities, see [SECURITY.md](SECURITY.md). Do NOT open a public issue.

### Community

- GitHub Discussions for Q&A
- GitHub Issues for bugs and feature requests
- Pull Requests for contributions

## Response Times

- **Bug reports**: Triaged within 1 week
- **Feature requests**: Reviewed within 2 weeks
- **Pull requests**: Initial review within 1 week
- **Security issues**: Acknowledged within 48 hours
